One commit message, at most 100 characters, for a bug fix that made
everything worse: the login page was removed to prevent login failures,
and zero failed logins have been reported since.

## Run

```sh
node main.ts
```

Writes the commit message to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–100 characters.
